Entry for [One Line, One Laugh](https://make.fun/bounty/u-plucky-finch-20-one-line-one-laugh-0ffe66ea) on make.fun — one funny line, max 200 characters, judged pairwise.

The concept is a comparison between two things that should never share a sentence: a trivial household object and a grand life ambition, forced together by a single shared routine. The joke lands on the last word, where the scale jump between the two finally collapses into one image.

> My houseplants and my dreams have the same care routine: water once, forget, apologize to the corpse.

## How to run

```sh
python3 main.py
```

This writes the entry line to `entry.txt` in `$OUTPUT_DIR` (default `/output`), with no trailing newline.
